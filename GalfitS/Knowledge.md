# 数据拟合与模型选择核心笔记

---

## 一、 约化卡方（Reduced Chi-Square, $\chi_\nu^2$）

### 1. 基础理论
约化卡方是用于评估模型**拟合优度（Goodness of Fit）**的核心统计量，衡量模型对带有不确定度的数据的解释能力。

* **卡方统计量（$\chi^2$）**：数据点偏离拟合曲线的加权残差平方和（$N$ 为观测数据点数，$\sigma_i$ 为测量误差）：
  $$\chi^2 = \sum_{i=1}^{N} \left( \frac{y_i - f(x_i)}{\sigma_i} \right)^2$$

* **自由度（Degrees of Freedom, $\nu$）**：数据点数量减去自由参数个数 $k$：
  $$\nu = N - k$$

* **约化卡方定义**：
  $$\chi_\nu^2 = \frac{\chi^2}{\nu} = \frac{1}{\nu} \sum_{i=1}^{N} \left( \frac{y_i - f(x_i)}{\sigma_i} \right)^2$$

### 2. 期望值与物理判定
在误差独立且服从高斯正态分布的假设下，$\chi^2$ 的数学期望值为 $\nu$，因此**约化卡方的数学期望值为 1**（即 $E[\chi_\nu^2] = 1$）。

| $\chi_\nu^2$ 数值 | 拟合状态 | 主要可能原因 |
| :--- | :--- | :--- |
| **$\approx 1$** | **理想拟合** | 模型很好地捕捉了物理信号，剩余残差纯粹为高斯噪声（约 68% 的点在 $1\sigma$ 误差棒内）。 |
| **$\gg 1$** | **拟合不足 / 误差偏小** | 模型物理机制不完整（欠拟合）、存在未考虑的系统误差，或实验误差 $\sigma_i$ 被低估。 |
| **$\ll 1$** | **过度拟合 / 误差偏大** | 模型参数过多（把随机噪声也拟合了），或者实验误差 $\sigma_i$ 估计过于保守（偏大）。 |

## 二、 贝叶斯信息准则（Bayesian Information Criterion, BIC）

### 1. 基础理论
BIC 是基于贝叶斯定理的**模型选择（Model Selection）**工具，旨在寻求**拟合精度**与**模型复杂度**之间的最佳平衡。

* **核心思想**：寻找使得给定数据下后验概率 $P(M|D)$ 最大化的模型。
* **数学公式**：通过对边际似然量进行拉普拉斯近似推导得到：
  $$\text{BIC} = k \ln(N) - 2 \ln(\hat{L})$$
  * $\hat{L}$：模型最大似然估计下的似然函数值（似然最大值）。
  * $k$：模型自由参数的个数。
  * $N$：样本点数量。

### 2. 结构与博弈机制
$$\text{BIC} = \underbrace{-2 \ln(\hat{L})}_{\text{拟合不足惩罚项}} + \underbrace{k \ln(N)}_{\text{模型复杂度惩罚项}}$$

* **BIC 数值越小越好**。
* 增加参数会提高似然值（使第一项减小），但也会增加复杂度（使第二项增大）。只有当新增参数显著改善拟合效果时，BIC 才会下降（体现**奥卡姆剃刀原理**）。

### 3. 高斯噪声条件下的转化公式
在测量误差服从高斯正态分布时，$-2\ln(\hat{L}) = \chi^2 + C$（$C$ 为常数），BIC 可直观写为：
$$\text{BIC} = \chi^2 + k \ln(N)$$

### 4. AIC 与 BIC 对比

| 指标 | 公式 | 复杂度惩罚 | 适用倾向 |
| :--- | :--- | :--- | :--- |
| **AIC** | $2k - 2\ln(\hat{L})$ | $2k$ | 侧重预测精度，倾向于选择稍复杂的模型 |
| **BIC** | $k\ln(N) - 2\ln(\hat{L})$ | $k\ln(N)$ | 侧重寻找真实物理模型，对复杂度惩罚更严厉（当 $N \ge 8$ 时） |

### 5. 模型比较判定标准（$\Delta\text{BIC}$）
假设有两个模型 A 和 B，记 $\Delta \text{BIC} = \text{BIC}_B - \text{BIC}_A$：

| $\Delta\text{BIC}$ | 对 BIC 较小模型（模型 A）的支持强度 |
| :--- | :--- |
| **0 ~ 2** | 弱（差异不显著，优先选参数少者） |
| **2 ~ 6** | 正面支持（建议选择模型 A） |
| **6 ~ 10** | 强支持 |
| **> 10** | 极强支持（几乎确定模型 A 显著更优） |
