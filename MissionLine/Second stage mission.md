# Second stage mission

As we have already known, the elliptical aperture of clump extraction in the analysis of G395H is tough. The elliptical aperture just included many pixels that didn't belong to the clumps. We need to construct a new aperture paradigm. I have an idea, which is using the flux contour map. You can find the pixels with highest flux of each clump firstly, and then set several levels of flux to figure the contour-line aperture. With those aperture you can also calculate the 1D spectra of each clump in each flux level. The most important technical problem is, what standard we require to set the level of contour? You can figure out your way, and show it to me. Create a new ipynb file to do this.

Moreover, if you have another proposal of a new aperture paradigm different from mine, just try yours together. You can create another ipynb file to do your trial parallelly.

After you get the 1D spectra of each clump by new aperture(s), please fit the lines in the same way of fit_spectra.py.
